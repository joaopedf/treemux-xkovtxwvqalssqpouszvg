# 🎙️ VoiceClip

**Create viral-worthy audio moments with AI**

VoiceClip is an AI-powered platform that helps content creators generate viral audio clips instantly. With trending prompts, AI script enhancement, and multiple voice styles, you can create TikTok/Instagram-ready audio in seconds.

## ✨ Features

- 🎯 **Trending Prompts**: Pre-loaded viral content starters
- 🤖 **AI Script Enhancement**: Powered by Claude to make your scripts more engaging
- 🎤 **6 Voice Styles**: Choose from Alloy, Echo, Fable, Onyx, Nova, and Shimmer
- ⚡ **Speed Control**: Adjust playback speed from 0.5x to 2.0x
- 🌊 **Animated Waveform**: Real-time audio visualization
- 💾 **Download Ready**: Export as MP3 for instant sharing

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh) installed
- OpenAI API key
- Anthropic API key

### Installation

```bash
# Install dependencies
bun install

# Create .env.local file
cp .env.example .env.local

# Add your API keys to .env.local
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key

# Run development server
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to start creating!

## 🛠️ Tech Stack

- **Framework**: Next.js 16 with App Router
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **AI Voice**: OpenAI TTS API
- **AI Enhancement**: Anthropic Claude 3.5 Sonnet
- **Runtime**: Bun
- **Deployment**: Vercel

## 🎨 How It Works

1. **Choose a trending prompt** or write your own script
2. **Click the sparkle button** to enhance your script with AI
3. **Select a voice style** and adjust the speed
4. **Hit Generate** to create your VoiceClip
5. **Watch the waveform** animate as you play
6. **Download and share** on TikTok, Instagram, or anywhere!
